# NJIX — Software & Digital Solutions

A responsive React + TypeScript + Vite company portfolio for NJIX, using the supplied navy-and-gold brand direction.

## Features
- Responsive single-page company website
- Services, featured project, company approach, and contact sections
- Gokul Traders project card linking to `https://gokul-traders.in/`
- Contact form opens a prefilled email draft (no backend or data storage)
- Mobile navigation and reduced-motion support

## Run locally
Requirements: Node.js 18+ and npm.

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build
```bash
npm run build
npm run preview
```

## Before publishing
- Confirm the business phone/email shown on the page.
- Replace the illustrative Gokul Traders preview with real screenshots, if available.
- Confirm project features and wording with the project owner.
- Add a backend/form service if you want enquiries to be stored rather than opened in the visitor's email application.
- Deploy the `dist` folder to a static host such as Vercel or Netlify.

The project preview art is illustrative and is not a screenshot of the live Gokul Traders website.
